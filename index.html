Fitur Lengkap

Teks & Keterbacaan

  • Perbesar / perkecil teks — sesuaikan ukuran font hingga +10px atau -4px
  • Spasi teks — tambah letter-spacing dan word-spacing
  • Jarak baris — perbesar line-height untuk keterbacaan lebih baik
  • Font disleksia — ganti ke OpenDyslexic, font khusus penderita disleksia
  • Panduan baca — garis horizontal mengikuti kursor

Warna & Kontras

  • Inversi warna — balik semua warna halaman
  • Latar gelap — dark mode instan via CSS filter
  • Abu-abu — mode grayscale seluruh halaman
  • Buta warna Deuteranopia — filter merah-hijau (tipe 1)
  • Buta warna Protanopia — filter merah-hijau (tipe 2)
  • Buta warna Tritanopia — filter biru-kuning

Navigasi & Motorik

  • Area klik besar — perbesar semua tombol dan link ke minimal 44×44px (standar WCAG)
  • Kursor besar — ganti kursor dengan ukuran lebih besar
  • Tombol dapat diseret — pindahkan tombol widget ke posisi nyaman (mouse & touch)

Konten & Gangguan

  • Sembunyikan gambar — sembunyikan semua gambar tanpa merusak layout
  • Stop GIF / video — bekukan animasi GIF dan hentikan video autoplay
  • Mode fokus — redup elemen non-konten agar fokus ke teks utama
  • Stop animasi — hentikan semua animasi dan transisi CSS
  • Aktifkan CC — paksa subtitle/caption video aktif

Konfigurasi

window.WAKConfig = {
  color: '#1a6fb5',   // warna tombol (hex)
  vside: 'bottom',    // 'bottom' atau 'top'
  hside: 'left',      // 'left' atau 'right'
  vval:  '24px',      // jarak vertikal
  hval:  '24px',      // jarak horizontal
  cols:  3,           // kolom grid: 2, 3, atau 4

  // Fitur yang disembunyikan:
  disabled: [
    // 'fontUp', 'fontDn', 'spasi', 'lineH',
    // 'bigclick', 'dyslexia', 'invert', 'dark',
    // 'gray', 'deuter', 'protan', 'tritan',

    // 'cursor', 'guide', 'anim', 'cc', 'reset'
  ]
};

Tentang Aksesibilitas Digital

Aksesibilitas digital memastikan bahwa website dan aplikasi dapat digunakan oleh semua orang, termasuk penyandang disabilitas. UU No. 8 Tahun 2016 tentang Penyandang Disabilitas mengamanatkan pemenuhan hak akses informasi bagi semua warga.

Menurut data WHO, sekitar 15% populasi dunia hidup dengan kondisi disabilitas. Artinya, dari setiap 100 pengunjung website Anda, sekitar 15 orang mungkin memiliki kebutuhan aksesibilitas yang berbeda — mulai dari gangguan penglihatan, disleksia, gangguan motorik, hingga buta warna.

Website yang aksesibel bukan hanya memenuhi kewajiban hukum, tetapi juga meningkatkan pengalaman semua pengguna — termasuk pengguna dengan koneksi lambat, layar kecil, atau yang mengakses konten di lingkungan dengan cahaya terang.

Tips Implementasi

  • Gunakan heading yang berurutan (H1, H2, H3)
  • Setiap gambar harus memiliki atribut alt yang deskriptif
  • Pastikan kontras teks minimal 4.5:1 (WCAG AA)
  • Semua fungsi harus dapat diakses dengan keyboard
  • Tambahkan link "Lewati ke konten utama" di bagian atas halaman
